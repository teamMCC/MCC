# apk/

공모전 제출용 release APK 를 이 폴더에 넣습니다.

- 파일명: `팀명_앱이름_release.apk` → 예: `teamMCC_MCC_release.apk`
- 만드는 법: Android Studio → Build Variants → `release` → Build → Build APK(s)
  → `app/build/outputs/apk/release/app-release.apk` 를 위 이름으로 바꿔 복사
- GitHub 업로드 용량을 넘으면 GitHub Releases 에 올리고, 루트 README 의 "4. APK 파일 위치"에 그 주소를 적습니다
